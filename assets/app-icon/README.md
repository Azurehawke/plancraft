# PlanCraft app icon

A page with a timescale header, three Gantt bars (one linked to the next by a dependency arrow)
and a milestone diamond, on a full-bleed PlanCraft-blue tile. Original geometry written by hand
for PlanCraft (2026-11-01), in the style of GridCraft's placeholder icon; not modelled on any
vendor's logo.

To change it, edit `plancraft.svg`, then regenerate the PNG, ICO and ICNS renders
(`packaging/icons.sh`, which needs `resvg`), and update the rows in `ATTRIBUTION.md`.
